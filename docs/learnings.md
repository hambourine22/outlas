# Factory learnings

One to three lines per entry. The thing a stranger on the next change benefits from without reading the trail. Newest at the top.

- **2026-10-31 · `resorts-motion`** — A canvas piece can stay inside the design system without naming a colour or a font: read the semantic CSS tokens with `getComputedStyle(document.documentElement)` at draw time (re-read on `data-theme` / `prefers-color-scheme` changes) and resolve the `next/font` families from `--font-*` on `<body>`, then `document.fonts.load()` them before the first frame — canvas text does not trigger font loading by itself. Timing, frame and weights belong in a `motion` token, not in the component.
- **2026-10-31 · `map-pin-rings` release** — `vercel --prod` uploads the *working tree*, and in a folder shared by several sessions that means other people's half-finished files ship. Release from a clean `git worktree` of the exact commit (recipe in the security-ops runbook); `qa-gate.sh` now builds an isolated copy of the working tree by default so a running dev server never again turns the full build into an opt-out.
- **2026-10-31 · `guides-apply-form`** — `useActionState` is a React 19 hook. This project runs React 18.3 under Next 14.2, so prerender throws `useActionState is not a function` and the whole route 500s. The 18/14 equivalent is `useFormState` from `react-dom` for `[state, formAction]` plus a child `<SubmitButton>` reading `useFormStatus()` for pending. The local `qa-gate` missed it because `SKIP_BUILD=1` had been set to work around a running dev server holding `.next/` — a release worktree (`git worktree add`) lets `next build` run clean and catches this class of error before deploy.
- **2026-10-31 · `world-mountain-resorts`** — Status/season/activity primitives live inside `MapPreviewSidebar.tsx` and are re-exported for the design-system specimen; keeping them in one file means `deriveStatus()` can stay a pure helper right next to the badge that calls it. If this pattern grows to a third category (not just resorts), split them to `app/ui/mapbox/primitives/` before the file passes ~500 lines.
- **2026-10-31 · `world-mountain-resorts`** — SVG season bars with CSS-grid letters below silently clip the final cell at narrow widths because `columnGap` interprets the ratio as absolute percent of width, not of a cell+gap unit. Put the month letters *inside* the SVG as `<text>` elements aligned to each cell's x — the viewBox then does the math and the letters never clip.
- **2026-10-31 · `world-mountain-resorts`** — Preflight RED on known-pending Next.js advisories isn't a silent-override case. Ask the user at deploy time with three concrete paths (ship as accepted risk / patch within major / full major bump) and record their choice in the release note under `## Accepted debt`. First time running the factory on a repo with pre-existing debt, this makes the decision explicit instead of eroding the gate's meaning.
- **2026-10-31 · `map-pin-rings`** — Mapbox circle pins: a 1px translucent stroke is all anti-alias fringe and reads soft; opaque rings (2px, then 1.5px) read heavy on the editorial basemap and were withdrawn. Final: fill only, integer radii stepped with zoom, one token (`mapPins`) so map, key and specimens never drift.
